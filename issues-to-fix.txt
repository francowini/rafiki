## 🧹 NITPICK ISSUES (5)

### 2. Add UnmarshalText for intensity type
**File:** `business/types/intensity/intensity.go` (lines 29-32)
**Issue:** `MarshalText` is implemented but there's no corresponding `UnmarshalText` method for unmarshaling from JSON/text formats.

**Suggested Implementation:**
```go
// UnmarshalText implements the encoding.TextUnmarshaler interface.
func (i *Intensity) UnmarshalText(data []byte) error {
	value, err := strconv.Atoi(string(data))
	if err != nil {
		return fmt.Errorf("invalid intensity value: %w", err)
	}

	parsed, err := Parse(value)
	if err != nil {
		return err
	}

	*i = parsed
	return nil
}
```

Add import: `"strconv"`

### 6. Align authentication order across handlers
**File:** `app/domain/momentapp/momentapp.go` (lines 50-77, 94-115, 155-176)
**Issue:** `update` and `delete` handlers call `QueryByID` before `mid.GetUserID`, whereas `queryByID` gets userID first. Unauthenticated requests to update/delete will reach the DB before being rejected.

**Recommended Pattern for consistency:**
1. Parse `moment_id`
2. Retrieve `userID` via `mid.GetUserID`
3. Fetch the moment
4. Enforce `moment.UserID == userID`
5. Apply update/delete

This mirrors `queryByID` and keeps all handlers following the same auth-before-data-access structure.

## ⚠️ UX ISSUE

### 7. Reconsider slider fallback behavior
**File:** `frontend/components/ui/slider.tsx` (lines 16-24)
**Issue:** When both `value` and `defaultValue` are undefined, `_values` falls back to `[min, max]`, creating a dual-thumb slider by default. Standard Radix patterns default to single-value sliders (e.g., `defaultValue={[50]}`).

**Required Action:**
Choose one of:
- Document that this component is designed for range sliders by default and require consumers to provide explicit values/defaultValue
- OR use a single-value fallback like `[min]` for consistency with typical slider UX

**Note:** This is a UX/design decision, not a Radix incompatibility.
